Hydrological Analytics

Machine Learning Pipeline & Ingestion Engine

How raw ensemble forecasts are enriched with soil moisture metrics to compute hyper-local inundation probabilities.

01

Open-Meteo Ingestion

Fetches GloFAS v4 daily ensemble discharge forecasts ($m^3/s$) across 0.05° spatial grid points via REST API.

02

Feature Engineering

Calculates 7-Day Antecedent Precipitation Index ($API_7$), discharge anomaly ratio ($Q_{ratio}$), and multi-layer soil saturation.

03

Inference Execution

Evaluates features against pre-loaded `joblib` XGBoost/Scikit-Learn model artifacts inside FastAPI worker memory.

04

GeoJSON Output

Outputs standardized risk classifications (Normal, Watch, Warning, Severe) injected into vector map layers.

Key Mathematical Formulations Used in Hydrological Pipeline
1. Antecedent Precipitation Index ($API_7$):
$$API_7 = \sum_{i=1}^{7} k^i \cdot P_i \quad (k \approx 0.85)$$

Models cumulative decay of ground wetness based on prior daily rainfall ($P_i$).

2. Discharge Anomaly Ratio ($Q_{ratio}$):
$$Q_{ratio} = \frac{Q_{forecast}}{Q_{median} + \epsilon}$$

Quantifies current forecasted flow relative to historical 38-year GloFAS median baseline.

Execution Roadmap

10-Week Engineering Implementation Plan

Stepwise development phases from initial setup to production cloud deployment.

WEEKS 01 - 02 Phase 01

Infrastructure Setup, Supabase PostGIS & Auth

Set up Git monorepo, configure Clerk Auth identity roles, provision Supabase database with `postgis` spatial extensions, and create base database tables.

WEEKS 03 - 04 Phase 02

Data Engineering, ML Training & FastAPI Docker

Ingest historical GloFAS / ERA5-Land datasets, train Scikit-Learn/XGBoost models in Jupyter, serialize `.joblib` model artifacts, and containerize FastAPI service with Docker.

WEEKS 05 - 06 Phase 03

React UI, Tailwind Styling & React-Leaflet GIS Map

Build React frontend SPA using Vite & Tailwind CSS, implement Leaflet map component with GeoJSON polygon rendering, and create citizen SOS dispatch modals.

WEEKS 07 - 08 Phase 04

Node Gateway, Resend Email Alerts & Realtime Sync

Develop Express gateway endpoints, integrate Resend email API for geofenced flood alerts, and subscribe React client to Supabase Realtime channels.

WEEKS 09 - 10 Phase 05

Cloud Launch (Vercel + Render), Testing & Defense

Deploy React frontend and Node serverless functions to Vercel, host Docker FastAPI microservice on Render, perform end-to-end testing, and prepare defense presentation.

Developer Reference

Database Schemas & API Specifications

Supabase PostgreSQL / PostGIS Schema Spatial Tables
Table: `incidents`
• id: UUID (Primary Key)
• severity_level: VARCHAR ('critical', 'high')
• location: GEOMETRY(Point, 4326) GIST Index
• status: VARCHAR ('pending', 'dispatched')
Table: `shelters`
• id: UUID | name: VARCHAR
• capacity_max: INT | capacity_current: INT
• location: GEOMETRY(Point, 4326)
Key REST API Contracts Endpoints
POST /api/v1/ml/predict-risk FastAPI ML

Accepts soil moisture & $API_7$ vector data, returns predicted risk score ($0.0 - 1.0$).

POST /api/v1/incidents/sos Node Gateway

Inserts citizen distress ping into PostGIS and triggers WebSocket notification to responders.

POST /api/v1/notifications/broadcast Resend API

Dispatches transactional warning emails to citizens inside active geofence zones.
